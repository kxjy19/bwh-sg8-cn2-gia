## 流媒体与 IP 的坑：TikTok 识别异常

买新加坡 VPS 的人很多冲着解锁当地服务去的，这里有个必须提前知道的细节。SG_8 使用广播 IP，TikTok 的风控目前把它识别为北美（加拿大）区域；而 Netflix、Disney+ 以及 ChatGPT、Claude 这类按实际物理出口判断的平台，已识别为新加坡并解锁当地原生内容。第三方测评给出的整体解锁率超过 85%。

另外，路由追踪日志里起始 IP 显示"荷兰（阿姆斯特丹）"也属正常现象——那是搬瓦工把其他地区 IP 段通过 Anycast/BGP 广播到新加坡机房，节点间延迟不足 2ms，可以排除物理绕路，判断线路以实际 AS 网络编号为准。做 TikTok 相关业务的话，SG_8 目前不合适；纯建站、AI 服务和主流流媒体不受影响。

还有一点要如实说：SG_8 目前三网 GIA 是实测结果，官方标称只承诺包含 China Mobile 和 CN2 GIA peering，测评方也提示了"不排除以后会变为三网优化"的可能。买之前把这个预期放进去。
